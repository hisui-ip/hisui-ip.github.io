配信と振り返りを支える、
そよつぐ本人のためのツール。

YouTubeの実績確認、ライブ配信のスケジュール管理、視聴者がコメントで参加する「何切る道場」を、本人のPCで運用します。

Google OAuthアプリ名：soyotsugu-analytics
本人専用のローカルツールです。このサイトは機能とデータの扱いを説明する案内ページで、一般向けのアカウント登録やログインは提供していません。

YouTubeの実績を確認

本人が管理するチャンネルの動画情報、再生数や視聴状況などの指標を取得し、動画制作や配信を振り返るための資料としてPC上で確認します。

配信をスケジュールで運用

事前に指定した日時・タイトル・概要欄でYouTubeのライブ配信枠を作成し、OBSと連携して開始・終了します。認証した本人のチャンネルで使う機能です。

コメントで参加する何切る道場

麻雀の手牌を見て、切る牌をライブコメントで回答する参加型の練習企画です。コメントを配信画面に表示し、正解や連勝を集計します。コメントの音声読み上げにはPC上の音声エンジンを使います。

自動運転では「そよつぐ」側の打牌をプログラムが選択します。配信画面と概要欄に自動運転であることを表示します。

データの扱い

Googleへのアクセスは本人が認証画面で許可した範囲で行い、取得情報と認証情報は本人のPCで管理します。ライブの公開コメントは配信画面や音声に使われます。詳しくはプライバシーポリシーをご覧ください。

このツールはYouTube API Servicesを利用します。YouTube利用規約およびGoogleプライバシーポリシーもご確認ください。
