プライバシーポリシー

対象：Google OAuthアプリ「soyotsugu-analytics」と、そよつぐ本人が運用する配信・分析ツール／何切る道場。

1. 取得する情報と目的

チャンネル・動画情報本人が管理するYouTubeチャンネルの識別情報、動画のタイトル・公開情報、再生数や視聴状況などの指標。動画制作と配信の振り返りに使います。
ライブ配信情報配信枠ID、開始・終了時刻、公開範囲、タイトル・概要欄、配信状態。本人が設定した配信の作成・開始・終了、接続確認、ライブチャットへの参加案内の投稿に使います。
公開コメントと回答YouTube等の公開ライブコメントの本文、表示名、投稿者ID、投稿時刻、投票結果。配信画面での表示、ローカル音声読み上げ、正解・連勝の集計に使います。投票の記録にこれらの情報が含まれる場合があります。
Google認証情報本人が許可したAPIアクセス用のトークン。許可された機能の実行と認証の更新に使います。Googleのパスワードはこのツールで取得・保存しません。

2. 保存とアクセス

取得データ、集計資料、ゲームの記録、認証情報は、運営者本人のPC上で管理します。公開するこの案内サイトには、認証トークン、ストリームキー、分析資料、コメントのログを掲載しません。保存済み資料は運営者が用途に応じて整理・削除します。

3. 表示・共有・外部サービス

公開ライブコメントは、何切る道場の配信画面への表示や音声読み上げ、連勝者の名前の演出などを通じて、他の視聴者にも伝わります。配信の録画・アーカイブにも残ることがあります。

GoogleへのAPIリクエスト、YouTube等への配信・接続、音声の配信は機能の実行に必要な範囲で行います。コメント読み上げの音声合成はPC上のVOICEVOX／AivisSpeechを使用します。取得したGoogleユーザーデータを広告目的で販売したり、汎用AIモデルの学習に利用したりしません。

Google APIから受け取った情報の利用および他のアプリへの転送は、Limited Useの要件を含むGoogle API Services User Data Policyに従います。YouTube API Servicesの利用にはYouTube利用規約が適用されます。Googleによるデータの扱いはGoogleプライバシーポリシーをご確認ください。

4. 許可の取り消しと削除

認証した本人は、Googleアカウントの接続管理からこのアプリへのアクセス許可を取り消せます。ローカルに保存済みの認証情報や取得資料の削除はPC側でも行います。Google側での許可取り消しだけで、保存済みのファイルが自動削除されることはありません。

公開コメントや投票記録の扱い・削除については、下記の運営者窓口へお問い合わせください。YouTube等の元のコメント、配信アーカイブ、PC上の記録はそれぞれ保存先が異なります。

5. この案内サイト

このサイト独自の広告、アクセス解析、入力フォームは設置していません。ホスティングにはGitHub Pagesを使用します。GitHubはセキュリティ等のためにアクセス元IPアドレスなどを取り扱う場合があります。詳しくはGitHubのプライバシーステートメントをご確認ください。
