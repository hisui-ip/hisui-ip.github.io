ツールの利用者

Google OAuthアプリ「soyotsugu-analytics」は、そよつぐ本人が管理するYouTubeチャンネルの分析・配信運用に使用するローカルツールです。現在、一般向けのアカウント登録、アプリの配布、有料サービスは提供していません。このサイトはアプリの内容とデータの扱いを説明するためのものです。

ライブへの参加

何切る道場への参加は、YouTube等の配信サービスの公開ライブコメントで行います。各サービスの利用規約・コミュニティガイドラインに従ってください。公開コメントは配信画面への表示や読み上げ、正解・連勝の集計などに使用され、アーカイブに残る場合があります。

自動運転とゲームの内容

自動運転中は、配信の開始・終了と「そよつぐ」側の打牌をプログラムが処理します。ボットの投稿はAI参加者として表示します。何切る道場は麻雀の練習・娯楽用の企画で、金銭の賭けや賞金の払い出しを行うものではありません。問題や判定に誤りがあれば、運営者へお知らせください。

YouTube API Services

このツールはYouTube API Servicesを利用します。YouTubeの利用にはYouTube利用規約が適用されます。データの扱いは、本サイトのプライバシーポリシーとGoogleプライバシーポリシーをご確認ください。
